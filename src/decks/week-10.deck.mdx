# The four moves

Diagnose → Acknowledge → Repair → Update

DIAGNOSE — Find the break precisely.

ACKNOWLEDGE — Name the miss to Mira.

REPAIR — Respond to this situation now.

UPDATE — Change the model so the failure matters later.

Update is the one that prevents replay

# Diagnose

Where exactly did the response go wrong?

MIRA · CURRENT CASE

Current message: "Can you stay with me for a bit tonight?"

Recent evidence: stayed in conversation longer this week; asked directly for company tonight

Old preference: When overwhelmed, Mira usually prefers space before talking.

AGENT RESPONSE

"Of course. Take all the space you need. I'm here whenever you're ready."

missed observation — Mira explicitly asked for company.

misapplied preference — Old pattern used as default.

wrong context assumption — Assumed "overwhelmed" still meant "space".

diagnosis must be specific

</div>

# Acknowledge

Name the miss to the cat you actually wronged.

TOO GENERIC

"Sorry about that. I should have responded better."

Why it falls short: admits a mistake; does not say what was misread; Mira still cannot tell what you understood

MORE SPECIFIC

"You asked me to stay, and I answered as if you had asked for space. I relied on an older pattern and missed what you were asking for tonight."

Why this helps: names the actual miss; shows Mira what you now understand; prepares a real repair instead of a vague reset

"sorry" is not enough

</div>

# Repair

Respond to the present situation, not just to the past mistake.

BAD RESPONSE — "Take all the space you need." — responded to old pattern

FAILURE NOTICED — "Wait — you asked me to stay." — noticed the fit break

ACTUAL REPAIR — "If you still want company, I can stay with you and keep it gentle." — responded to Mira now

repair serves the current interaction

</div>

# Update

If the model does not change, the failure will repeat.

MIRA CARE MODEL v1.5

When overwhelmed, Mira usually prefers space before talking.

confidence: KEEP · risk: too absolute · used as default

MIRA CARE MODEL v1.6

When overwhelmed, Mira often prefers quiet decompression first — but recent evidence suggests she may also want gentle company, especially when she asks directly for it.

confidence: HOLD LIGHTLY · new condition: check current request first · uncertainty restored honestly

lower confidence + add condition

</div>

<div class="sr-only">

# What a real update looks like

Updates can be small, but they must change future care.

LOWER CONFIDENCE — KEEP → HOLD LIGHTLY — The old pattern still matters, but with less force.

ADD A CONDITION — "if she asks directly" — A useful rule becomes more specific instead of more rigid.

RESTORE UNCERTAINTY — watch next time — The honest model may include not yet knowing.

small revision, real consequence

</div>
