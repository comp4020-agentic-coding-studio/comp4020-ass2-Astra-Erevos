# Assessment

Four pieces of work carry the semester. Care Labs (10%) reward showing up
and doing the weekly work. Catwatch (15%), The Care Model (25%), and Know
Your Cat (50%) are one continuous project on the same human cat: observe
first, then build a model of them, then keep that model honest as they
change.
