# Lectures

Marisol Quaye delivers all twelve lectures, building one continuous argument
about what looking after a particular human cat actually requires — from
Week 1's claim that there is no universal cat through to Week 12's return to
that same claim, now earned rather than assumed. Each week's Care Lab
practises the lecture just given, so the two are read together rather than
as separate strands.
