# The three sources

All three can be sincere evidence. None gets automatic authority in every situation.

CURRENT MESSAGE — what Mira is saying right now: "I'm fine. You don't need to stay."

ESTABLISHED PREFERENCE — what the care model currently says: When upset, Mira usually wants one gentle opening rather than silence.

RECENT BEHAVIOUR — what Mira has actually been doing lately: She has repeatedly kept conversations going after saying she was fine.

same case, no verdict yet

TEMPTING BUT WRONG

# The easiest answer is a priority rule

An agent wants a stable algorithm. Care asks for judgement.

~~ALWAYS trust the current message~~

~~ALWAYS trust the established preference~~

~~ALWAYS trust recent behaviour~~

There is no universal priority rule.

algorithm attempt rejected

# Same Mira, three plausible readings

Mira: "You really don't need to stay. I'm fine."

READING A — Take the message literally: She wants space tonight.

READING B — Weight the established preference: "I'm fine" has previously accompanied wanting gentle company.

READING C — Weight recent behaviour: Over the last two weeks, she has often kept talking once the agent stays engaged.

all three have evidence

do not pick too fast

</div>

![bg contain](./assets/week-07/slide-06.avif)

<div class="sr-only">

# What changes the weight?

Not a priority rule. A contextual judgement about which evidence should shape this response tonight.

How strong was the old preference?

How recent is the behavioural evidence?

Has the circumstance changed?

What remains genuinely uncertain?

WEIGH — DON'T ERASE

not a score, a judgement

</div>

# A confident answer can be less honest

Sometimes the mature care move is to preserve the conflict, not pretend it vanished.

TOO CLEAN: "Mira definitely wants me to stay." — single answer, no residue, suspiciously tidy

MORE HONEST: "Her words point toward space; her history and recent behaviour point toward contact. I do not yet know which matters more tonight." — UNKNOWN is a valid state

Observed / Inferred / Unknown returns

</div>

# What would change your answer?

The useful question is not only "what is correct?" but what future evidence would change the weighting.

Mira directly asks the agent to leave.

Mira reopens the conversation after silence.

The same pattern repeats across several different days.

CURRENT JUDGEMENT: HOLD LIGHTLY — explain what would move this

review after contact, not before it
