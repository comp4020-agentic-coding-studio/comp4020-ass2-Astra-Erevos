# Your cat is not a context window.

A context window asks what fits now. Care asks what deserves to shape what
happens next.

</div>

---

![bg contain](./assets/week-05/slide-03.avif)

<div class="sr-only">

# Remembering everything is not remembering well

## Archive: "Keep it all."

Maximises retention. Treats old and new evidence alike. Preserves detail
without judgement.

## Care Memory: "Carry forward what still matters."

Selects for current relevance. Carries confidence, not certainty. Leaves
room for change.

Selection is judgement. Memory is part of care, not just infrastructure.

</div>

---

![bg contain](./assets/week-05/slide-04.avif)

<div class="sr-only">

# Which histories travel forward?

Two different questions. Two different dimensions.

## Week 4 — what kind of history is this?

Recurring pattern: repeated across situations. One-off event: important, but
singular. Shared convention: meaning built together. Uncertain history:
evidence still incomplete.

## Week 5 — how strongly should it shape care now?

Keep, Hold Lightly, or Let Expire. Not a mapping — the same history type can
land in different memory states.

</div>

![bg contain](./assets/week-05/slide-05.avif)

<div class="sr-only">

# Keep / Hold Lightly / Let Expire

These are current care states, not permanent filing categories.

## Keep — actively carry forward

High enough confidence and relevance to shape current care.

## Hold Lightly — useful, but provisional

Keep it available. Keep checking it against new evidence.

## Let Expire — stop active influence

Do not let it shape present responses unless new evidence revives it.

Even KEEP can change. Persistence is a decision you can revise.

</div>

# Same cat, changing evidence

Designated Human Cat: Mira.

## Week 2 — old pattern

After a bad day, Mira usually wants space. Keep, confidence 0.82 — later
revised.

## Week 5 — new evidence

"Stay with me." She keeps talking — twice. The old rule is losing
confidence.

## Revised memory

After a bad day, Mira may want space — unless she asks for company. Check
the current cue. Hold Lightly, confidence 0.55.

The cat did not "contradict the profile." The model learned: same cat, same
relationship, revised belief.

</div>

<div class="sr-only">

# The static profile trap

A tidy profile can preserve the past while destroying the present.

## Mira · Profile v1.0

Bad day → wants space (Always). Comfort style → minimal questions (Fixed).
Preferred interaction → silence first (Fixed). Last updated: Week 2. Status:
Outdated.

It used to work. That is what makes it dangerous. A static profile mistakes
"was true" for "is true".

</div>

<div class="sr-only">

# Memory must have confidence and persistence

A useful memory is more than a sentence.

## 1 · Confidence — how sure am I?

Evidence strength should travel with the claim. Confidence: 0.55.

## 2 · Persistence — how long should this keep shaping care?

KEEP is not forever. Review can move any state.

## 3 · Revision condition — what would make me change my mind?

New language? Repeated behaviour? A changed routine?

Memory = claim + confidence + review condition. Careful memory keeps a door
open for the cat to become different.

</div>

# Memory should preserve continuity without freezing the cat.

Know what to carry forward. Know what to question. Know what to let go.

Keep → can change. Old ≠ wrong. Old ≠ current.

There is no universal cat.
