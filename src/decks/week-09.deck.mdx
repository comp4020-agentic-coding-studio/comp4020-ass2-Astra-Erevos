# The old preference was applied outside its context

Correct memory + wrong context = bad personalisation.

WHAT THE MODEL REMEMBERED — Mira often wants space when overwhelmed.

WHAT THE AGENT MISSED — Mira explicitly asked for company this time.

WHAT WENT WRONG — A preference became a default response.

Do not blame memory for an application error.

memory okay; use wrong

# Failure is evidence

A failure you can name precisely is useful evidence.

FAILURE LOG

What did I observe? — Mira directly asked me to stay.

What did I rely on? — An old preference for space.

Where did the fit break? — I treated the preference as current without checking context.

What is still unknown? — Whether tonight is an exception or evidence of broader change.

do not repair yet — first find the break
